# Dracos Core

Server-side Fabric mod (1.21.11) pre Dracos SMP. Hraci nepotrebuju ziadny mod.

- `/sell` - okno na predaj, po zavreti dostanes peniaze (ceny z `/shop`, Burger Economy)
- `/sell hand` - preda vec v ruke
- `/legendary` - obchod s legendarnymi vecami
- `/dracos give <hrac> <item>` - admin

Legendary: Shard Pickaxe (3x3), Dragon Blade (dash), Lava Axe (ohen + cely strom), Void Bow (sipy bez gravitacie), Draco armor set (Speed + Fire Resistance, +srdcia).

Build: GitHub Actions -> artifact `dracos-core`.
