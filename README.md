# Dracos Core

Server-side Fabric mod (1.21.11) for Dracos SMP. Players need no client mod.

- `/sell` - sell window, close it to get paid (prices from `/shop`, Burger Economy)
- `/sell hand` - sells the item in your hand
- `/legendary` - legendary item shop
- `/dracos give <hrac> <item>` - admin

Legendary: Shard Pickaxe (3x3), Dragon Blade (dash), Lava Axe (fire + whole tree), Void Bow (no-gravity arrows), Draco armor set (Speed + Fire Resistance, +hearts).

Build: GitHub Actions -> artifact `dracos-core`.
